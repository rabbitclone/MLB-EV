Configure your GitHub repo below. Every time you log a result or add a pick, the dashboard HTML (with all embedded data) is pushed to your repo automatically. Your full pick history, analyses, and intelligence flags are preserved in the file itself.

How to set up
  1. Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate a token with repo scope
  3. Your repo is pre-set to rabbitclone/mlbtable — no changes needed
  4. Paste your token above and click Save config
  5. Click Push to GitHub now — the dashboard HTML is committed to your repo as index.html
  6. Enable GitHub Pages on the repo: Settings → Pages → Deploy from branch → main → / (root) → Save
  7. Your live URL will be: https://rabbitclone.github.io/mlbtable/
  8. Every result you log auto-pushes an updated version to the repo
